Using the files

  • Copy the .bin files into the assets folder on the display's SD card, or upload them on the display's Assets page.
  • Then pick the background for a screen on the display's Gauge Calibration page.
  • Icons stay as PNG: only backgrounds need converting.
Tip: design at 480 × 480All the displays are 480 × 480 pixels. Start your design at that size and nothing gets cropped or scaled. On the Round displays only the circle in the middle is visible: tick Show as a Round display to check what's cut off.
Backgrounds must be squareThe display works out the image size from the file size, assuming it's square. That's why this page always makes a square image. A non-square .bin from elsewhere will show up scrambled.

Same result as the convert_png_to_rgb565.py script in the repository: raw RGB565 pixels, 2 bytes each, little-endian, no header. A 480 × 480 background is 460,800 bytes.
