2. Set up the screen

  1. After installing, the screen starts its own WiFi network (see the table below).
  2. Join that network on your phone or laptop, then browse to http://192.168.4.1.
  3. Enter your boat's WiFi details and, for Signal K screens, your Signal K server. Save, and the screen restarts and joins your WiFi.
  4. From then on, open the screen's web page at its IP address on the boat's network to set up pages, gauges and alerts.

If it doesn't work

  1. No port to choose: try a different cable, because some only carry power. If it still doesn't show up, hold the BOOT button while plugging the cable in, then click Connect again.
  2. On Windows the port doesn't appear: you may need the USB-serial driver for the board's USB chip (CH343/CH340) from the chip maker's site.
  3. Screen stays blank after installing: unplug it and plug it back in.
  4. Still stuck? Open an issue on GitHub and say which screen you have.
